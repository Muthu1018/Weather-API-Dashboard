## 📌 About the Project

The **Weather API Dashboard** is a data analytics project developed using
**Python, Excel, and Power BI** to analyze and visualize weather-related data.

The dashboard presents weather information through interactive visuals,
making it easier to understand weather conditions, measurements, and trends.

---

## 🎯 Project Objectives

- 🌦️ Analyze weather-related data
- 📊 Create interactive weather visualizations
- 🌡️ Understand temperature variations
- 💧 Analyze humidity and atmospheric conditions
- 💨 Explore wind speed and visibility
- 🌧️ Analyze precipitation and weather conditions
- 📈 Present weather information through an interactive dashboard
